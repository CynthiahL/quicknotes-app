# Notes App

A lightweight web application for creating, categorizing, searching, and managing notes. Built with HTML5, CSS3, and vanilla JavaScript, it demonstrates semantic structure, responsive design, validation, persistence with localStorage, and interactive features.

## Features
- Add notes with categories (Personal, Work, Study).
- Validation: prevents empty notes or notes over 200 characters.
- Delete individual notes with confirmation.
- Clear all notes with confirmation.
- Live search filter for notes.
- Notes saved in localStorage (persist after refresh).
- Responsive design with Flexbox and media queries.
- Category-specific styling for notes.
